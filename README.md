# DBTournament

Dragon Block Z Reborn: Tournament of Power development project, scripts, assets, notes, and tooling.

## Overview
- **Vault & Design Notes**: Game design documents, execution plans, and mechanics notes in `vault/` and root `.md` files.
- **Tools & Automation**: Automation scripts, asset extractors, and inspection tools in `tools/` and root `.py` / `.lua` files.
- **Models & Assets**: 3D character models and environments in `models/`, `sketchfab/`, and `sketchfab_out/`.
